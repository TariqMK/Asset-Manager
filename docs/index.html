    Watched folders
    Any folder on a local disk, an external drive or a network share, with or without subfolders.
    
        
    Drag and drop
    Drop images onto the window to add files that live outside your watched folders.
    
        
    Tags and notes
    Tag any image and add free-form notes. Every tag shows its file count.
    
        
    Nested collections
    Group images by project, in any folder structure you like. One image can be in many collections.
    
        
    Smart collections
    Collections built from tag rules that update themselves.
    
        
    Search
    Find images by file name, tag or note text.
    
        
    Missing files
    Moved files are listed under Missing, with their tags kept. Relink them in one step.
    
        
    Offline drives
    A folder that can't be reached is marked offline. Its files are not flagged as missing.
    
        
    Plain JSON library
    Saved in one folder, written in one step so a crash can't leave half a file.
